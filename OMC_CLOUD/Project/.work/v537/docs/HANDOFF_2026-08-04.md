## 1. THE INTERRUPTED TASK — independent spec-only decoder (C8)

### 1.1 Why it exists

C8 requires a bitstream that a second vendor can implement from the
document. Minors 0–2 were validated that way historically; minors 3–7
(block-MV field, entropy-v2 tables, correlated tile, amplitude-matched
fill, static fill) have only ever been decoded by OUR decoder. The
exercise proves the DOCUMENT is sufficient — the deliverable that
matters is not the decoder but the list of places where the document
turned out NOT to be sufficient.

### 1.4 The verification ladder (the plan that was running)

Climb in this order; each rung isolates one subsystem, so the first
failing rung names the guilty stage:

1. **Stream header** — parse the 32 bytes of `c2_legacy_tables.omc`,
   check against BITSTREAM §2. (Almost certainly passing: `cmd_header`
   exists and is the simplest rung.)
2. **Slice header** — frame 0, slice 0, all fields of §3.1.
3. **tANS + symbols** — table construction from the normative counts,
   backward state machine, category/raw decode.
4. **Transform-domain stage check** — decode frame 1 / slice 0 of
   `c7_static_fill.omc` and compare the composed coefficient buffers
   against `delivery/conformance/traces/gt_c7_static_fill.coef.p{0,1,2}.i32`
   (int32 LE). This is the highest-value rung: it isolates everything
   before the inverse transform. Note frame 1 requires frame 0 decoded
   first (prediction reference).
5. **Inverse transform** — compare against
   `traces/gt_c7_static_fill.recon.p{0,1,2}.u16`.
6. **Full-stream hashes** — all nine vectors in
   `delivery/conformance/vectors/`, each against
   `expected/<name>.decode.sha256`. Suggested order (easiest first):
   `c2_legacy_tables` → `c7_base_444_12` → `c4_entropy_v2` →
   `c7_static_fill` → `c6_gr_corr` → `c4_blockmv` → `c6_blockmv` →
   `c_midjoin` → `c_loss_conceal` (concealment last: it is the only
   vector whose correct output depends on normative *error* behavior).

### 1.5 Spec gaps found so far (SPEC_GAPS.md must be created)

Only one is confirmed, and it is real:

- **GAP-1 — allocation tables were not in the document. FIXED
  2026-08-04.** BITSTREAM.md §6 designated `omc_off[4][3][10]`,
  `omc_off_c444[10]` and `omc_refine_order[]` as normative but pointed
  at `src/alloc.c` instead of tabulating them — a vendor holding only
  the specification could not derive per-band quantizer shifts, i.e.
  could not decode any stream. The spec-decoder agent had to read
  `src/alloc.c` as data, which surfaced the gap. **Fix applied:**
  BITSTREAM.md now carries **Annex A** with all three tables in full
  (120 + 10 offsets, 49 refinement steps), transcribed mechanically and
  verified against the compiled constants (`omc_refine_steps == 49`,
  spot-checked endpoints). §6 now points at Annex A.
  - Nit found while verifying: a comment in `src/codec.c` (v4.3 MV-field
    note) still says "omc_refine_steps = 52"; the real value is 49. The
    argument it supports (n_steps fits in 7 bits, so bit 7 is free as
    the MV-field flag) is unaffected. Correct the comment when next in
    that file.
- Any further gaps must be recorded as the ladder is climbed. The
  agent's brief was: when the document does not answer a question,
  record the section and the missing fact rather than reading the
  implementation. Preserve that rule on resume.

## 2. OTHER OPEN WORK (state and next action)

### 2.1 F-4 unclipped reference — validated prototype, NOT shippable yet
- **State:** implemented behind `OMC_REF_UNCLIPPED=1` (both codec ends),
  REPORT §18.11. Rail-content generation chain goes from a hard floor
  (~64.9 dB, A4 failing) to monotone convergence (62.6 → 71.3 dB rising).
  Flag OFF is byte-identical to the pre-fix encoder (independently
  re-verified). rt=0 with the flag on. Unit suite green both ways.
- **Blocker:** `conceal_mc_plane` / `conceal_spatial_plane` (~codec.c
  L2495–2570) read and write the reference WITHOUT the bias. With the
  flag on, a LOSSY stream would conceal from mis-scaled samples and
  corrupt the reference. Clean-stream gates never exercise this.
- **Next actions, in order:** (1) make both concealment paths
  bias-aware; (2) add a lossy-stream gate (corrupt a slice, decode,
  compare to the flag-off concealment behavior); (3) only then plumb
  bitstream **minor 8** (a decoder must know the reference convention —
  this is NOT encoder-only); (4) new conformance vector class
  `c8_unclipped_ref` + traces; (5) BITSTREAM §9.6 + ledger E-12.
- **Do not** flip the default before (1)–(5).

### 2.2 mms — the corpus's one equal-rate VMAF loss

  XS@2 96.815, XS@4 97.555 — the only clip where OMC loses at equal

## 4. HOW TO VERIFY ANY CLAIM IN THIS FILE

- Build + gates: `cd omc2 && make -j8 && ./test_unit` (expect `all ok`).
- Conformance: `cd omc2/delivery/conformance`, decode each vector with
  `../../omc_dec` and compare to `expected/*.decode.sha256`.
- Golden traces: `OMC_TRACE=<prefix> OMC_TRACE_FRAME=1 OMC_TRACE_SLICE=0
  omc_dec -i <vector> -o /dev/null`, then compare with `traces/`.
- Box/ants instrument: `work/box_compare.py <decode.yuv> <label>`.
- Geometry: ALWAYS from `work/final_sweep.py` CLIPS table — two clips
  (soccer, mms) were measured at wrong geometry for days because it was
  assumed instead. `omc_enc` now warns when a raw file is not a whole
  number of frames; heed it.
