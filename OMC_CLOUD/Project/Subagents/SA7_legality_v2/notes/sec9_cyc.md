## §9.5 (d) Cycles — the two-phase pass plus the residue escape, per slice

Conventions as DESIGN §3 (A-1…A-5): one traversal of a slice = `N/w` cycles at width `w`; the base
encode is a streaming flow costing `A` traversals; the correction is a re-entry whose stages add.
Measured inputs from §9.2: **`V` (violating samples per slice) p50 2–13, max 183 = 0.30 % of `N`**;
the two-phase pass runs **at most `K = 2`** phase pairs.

**Per phase.**

| stage | cost | scales with |
|---|---|---|
| phase 1: for each violating sample, scan its covering level-1/level-2 atoms (≤ 24 by index arithmetic, `Ka = 4` kept) and one LUT read + one add | `Ka × V` ops | V |
| phase 2: apply the accumulated demands | `≤ V` ops | V |
| phase 2: **exact local inverse** over the union of touched supports + lifting halo | `3.4375 × C` traversals | C |
| phase 2: re-census that region | `1.0 × C` traversals | C |

`T_pass = K × (Ka·V/N + 4.4375·C)`. At the measured worst `V/N = 0.0030`, `Ka = 4`, `K = 2`:
`2 × (0.012 + 4.4375·C)`. With `C` capped at 4 % of the slice: **0.379 traversals**. At the 13 %
upper bound of §7.6: **1.18 traversals**.

**The residue escape** adds, on the ≤ 3 % of slices that need it: one more phase pair
(`+0.19 … +0.59`) plus the escape list's entropy coding, which rides in the **single** entropy pass
the slice already makes (the Stage-B reorder) and costs bits, not cycles.

**No re-code.** The whole-step half emits ordinary lattice points at the signalled plan, so the
corrected slice is coded exactly once. This is the property §9.2's arm demonstrates by construction:
the armed encoder writes the corrected coefficients and the stream is exact-CBR with **no syntax
change at all**.

**Per slice, worst case, `A = 1`, correction + residue escape, with the reorder:**

| format | period (cyc) | traversal @ w=8 | total @ w=8 | of period | @ w=16 | of period |
|---|---|---|---|---|---|---|
| 720p60 | 55,556 | 2,560 | (1 + 0.379 + 0.19) × 2,560 = 4,016 | **7.2 %** | 2,008 | 3.6 % |
| 1080p60 | 73,529 | 7,680 | 12,049 | **16.4 %** | 6,025 | 8.2 % |
| **4K60** | 37,037 | 15,360 | 24,099 | **65.1 %** | 12,049 | **32.5 %** |
| 8K60 | 18,519 | 30,720 | 48,197 | ✗ | 24,099 | ✗ (base alone 83 % @ w=16) |

At the 13 % `C` bound: 4K/w=8 becomes 115 % and fails, **4K/w=16 is 57.5 % and holds**. The GO bar
asks for 4K inside the period at 16 spc: **met, with 42 % of the period to spare at the 4 % cap and
17 % at the 13 % bound.** 8K remains a base-encode throughput fact (≥ 32 spc), unchanged by this
iteration.

**Against what it replaces** (measured, §1 and §7.6): the shipped constructive step runs **p50 17
and max 741 full-plane inverses** per slice = 29.2 and 1,273.6 traversals. The two-phase pass with
an exact local inverse is **0.38 traversals worst case** — a factor of **3,350 at the worst slice**
— and it is the only part of this whole investigation whose cost is not the problem.

## §9.7 (f) Provenance — every element

| element | provenance | why it is obviously clean |
|---|---|---|
| the two-phase correction (accumulate demands onto shared atoms → apply → verify by an exact local inverse) | own work | it is an assignment loop and this codec's own lifting arithmetic on a sub-rectangle |
| the atom response table (`latt_bas`, impulse through `omc_slice_inv_p`, Q12) | already in this tree (`src/latt_probe.inc`), own work | it is a measurement of our own transform |
| the supports (`GM_BASIS`, `gm_basis_tab.c.inc`) | already in this tree, generated by `repro/gen_gm_basis.c` | ours, and already shipped |
| the wash guard (`latt_blockshift` form 4) | already in this tree | ours, and already shipped |
| the causal bank and the 2× wire cap | **already normative in this codec** (`src/codec.c:5986`, BITSTREAM §5) | nothing new is introduced; the residue escape spends an allowance that already exists |
| within-bin escape, its window, its flat position list, Elias-gamma positions, tANS values | as §7.10 | unchanged |
| the `verify_candidate` extension | own work, four lines plus the window function | it is a predicate on this codec's own quantiser |

**Left out under the rule** (not flagged): an embedded/truncatable escape ordering; a
quantisation-weight table; any per-block or per-region step-offset syntax. None is present.
