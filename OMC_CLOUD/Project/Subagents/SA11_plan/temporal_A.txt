=========================== 2. MECHANISMS IN THE CURRENT CODEC THAT CAN MOVE A STATIC AREA ============
(rtree4 src/codec.c line numbers; rtree4 = v537 + R1 work, the product path is shared; OMC_R1 unset)
 M1 Rolling intra refresh: slice s is intra on frame f when fidx8 % R == s % R, R = 8 default
    (codec.c:2738-2747).  Intra and inter stationary points differ -> period-R pulse (A4, A7).  Refresh
    boost OMC_RBOOST=50 gives refreshed slices +50 % budget (codec.c:3462, 10023).
 M2 Fresh rate control every frame (Q loop 12273, refine loop 12289) -> plan wander on near-ties (A6).
    Mitigation: static-slice hold level 3 (codec.c:12358ff; inter: est(old) <= budget*35 %; intra
    refresh slices: rhyst/rcyc_static branch 12321ff).  Slices whose residual cost exceeds 35 % of
    budget (real grain, low rates) replan every frame.
 M3 Inter residual re-coded every frame: the inter band codes coef - pcoef, pcoef = forward transform of
    the motion-compensated previous committed picture (predict_plane 4546).  On a static SOURCE the
    residual is (source - previous decode) = the codec's own quantisation error, which is re-quantised
    and re-sent every frame -- no hold-still/zero-residual rule exists in OMC (C1 is the HVBC form).
    Q5 skip (codec.c:1720-1730; on by default OMC_Q5FLAG=16, 3200) only drops coefficients whose q is
    already 0 (inter) or == quant(pcoef) (intra): reconstruction-preserving, rate only, never holds.
 M4 Per-band mode decision BMODE = bits_inter < bits_intra (codec.c:10586): recomputed each frame from
    noisy costs; reference noise flips 7-30 % of bands (B2).  A band flipping intra<->inter moves between
    the two stationary points.
 M5 Deadzone / calm kill (dz_enabled 3510; OMC_CALM 3181): zero-zone around the 0/1 boundary; ants
    mechanism A4 is what survives outside the calm class (LL gradient >= threshold, |coef| >= amp).
 M6 Causal bit banking (avail_prefix codec.c:9903; budget_hard): a change in any earlier slice's spend
    moves every later slice's budget -> plan/refinement changes cascade down the frame.
 M7 OMC_ALLOC (codec.c:9977): per-slice budget cap from the PREVIOUS frame's energy record.
 M8 Targeted partial / PBAND / PLAN-SD (codec.c:12601, 12544ff, 12433): chunk selections derived from the
    quantised LL; follow LL changes.  spc depth clamp toward the previous slice (12646).
 M9 XSL seam blend (xsl_prep codec.c:9802): slice k's transform uses rows of slice k-1's committed
    reconstruction -- any change in slice k-1 perturbs slice k's top rows (B2.1 says not the carrier).
 M10 Derived motion (derive_mv 4970): zero on frozen content (A6: exonerated); on real clips moving
    neighbours' vectors reach static samples.
 M11 Gamut repair (shipped default ON, omc_enc.c:76) and DCFB (OMC_DCFB default 0, codec.c:3441): repair
    edits coefficients per slice from the per-frame picture.
 M12 Grain fill: OFF by default (--fill); when on, tile static but amplitude follows the plan shift (A8).
 M13 Transform support spill-over: a changing sample moves every coefficient whose support covers it
    (level-5 LL supports hundreds of samples, S5.317 f5) -> static samples near motion change even with
    perfect coding (the W6 caveat; Part B splits by distance).
