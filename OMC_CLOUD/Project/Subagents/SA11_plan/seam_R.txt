================ 1. HOW SLICES ARE JOINED TODAY, AND WHY ================
 1.1 Why: slices are coded independently (slice_h lines); rows 0 and sh-1 carry 30-60 % excess quantisation noise
     energy; the eye integrates it into a horizontal line at every join; the incumbent has none (XSL "Why it exists";
     BS ~872-874 "band-fix memo §21-26 ... eye gate passed with this fix").
 1.2 Cross-slice (XSL) transform term: slice k's vertical level-1 lifting takes d[-1] = r15 - 2 r14 + r13 of slice
     k-1's COMMITTED reconstruction (was a copy of d[0]) (BS ~815-822 (a)); computed per slice by xsl_prep
     (rtree4 codec.c:9802), fed to three sites: prediction forward, reconstruct_slice inverse (both ends), source
     forward (LSv2 S5.206 L3232).  Live in the shipped build; setting it to 0 costs -0.17...-0.46 dB mean, -3.7 dB
     worst frame (spotrobotL @1.0), chroma <= 0.03 (S5.206).  S5.202 L3220: the d[-1] term feeds the level-1 update.
 1.3 Boundary edit / display blend.  Level 3 (minor 9, shipped v4.14 default): row 0 blended toward (prev r15 +
     r1)/2, prev r15 toward (r14 + r0)/2, cap ±lim, "applied to reference AND display" (BS ~815-822 (b),(c); XSL
     "Levels").  Cap (lim) normative, rate-derived: 8 codes (10-bit) below 0.75 bpp on coded samples, 4 at/above;
     x((maxv+1)>>10) by depth; 4:4:4 threshold 1.125 bpp; 0 at 8-bit (F-14) (BS ~824-866; T5 ~630-640; XSL "The
     blend cap"; eye-chosen, SL12 PART V L632: cap 4/8/16 sweep @0.5 seam +1.23/+0.67/+0.40, @1.0 +0.00/-0.35).
 1.4 T5 form (current): the edit is a reversible two-step lifting cascade (XSL "Level 7"; T5 5.3(b) ~617-643):
     step 1 row15 += clamp(div(row0 - row14), ±lim); step 2 row0 += clamp(div(row15' - row1), ±lim); rows 14 and 1
     never written; applied unconditionally in the wide domain.  LOOPFREE (candidate L, OMC_XSL_LOOPFREE=1, shipped):
     the interior edit is DISPLAY-ONLY, off the reference (L53 L154, L5285-5320: loop gain 9.6 -> 1.9 %/frame @2.0,
     4.9 -> 0.2 % @0.5, 72-90 % of the seam repair retained; CONTROL_PLANE.md:487).  Reviewer verified loopfree = 1
     at runtime (LSv2 S5.202 L3220).  CASC (OMC_XSL_CASC, four-row cascade) default 0 (L53 55.8c/d).
 1.5 Refresh barriers (A5): a slice intra-refreshed this frame takes no cross-slice terms and no edit; slice k skips
     the retro edit of k-1 when k-1 is refreshed (BS ~876-886 (d),(e); XSL "Refresh barriers"); without them a lost
     slice's divergence "decay stalls at ~10 codes and creeps one slice per cycle".  Barrier DISPLAY blend (f): the
     raw boundaries get the same cascade on the EMITTED picture only (BS ~888-900: step excess 3.1 -> 6.6 codes
     without it, 3.3 with it; T5 (c) ~645-653).  H0 measured it (SA11_plan/hold_H0.txt; LSv2 S5.336): with zero
     residuals, only displayed row 0 / last row next to a refreshed slice change (350/880/1,188 samples).
 1.6 Un-blend at the next encoder: omc_enc_frame applies omc_xsl_unblend to every input frame (exact inverse of the
     interior cascade + barrier display blend, bottom-up, per boundary kref / k1ref / interior), detector-free; on
     masters it pre-distorts boundary rows within ±lim which the decoder's forward edit cancels; 2-line lookahead
     (T5 ~655-670; XSL "Level 7" limits 1-2).  Measured cost on masters: the blend still removes 54-70 % of seam step
     excess (T5 10.4 ~1147-1175: cine @0.5 +1.69 vs +4.36 no-edit codes; @1.0 +0.79 vs +2.64; gfx444 @0.5 +1.35 vs
     +2.95; @1.0 +0.77 vs +1.88; source ~+0.2).  XSL "Level 7" limit 1: always un-blending first-generation
     material loses ~1/3 of the repair (beach @0.5 +2.903 -> +4.873).
 1.7 Owner rulings: T5 ~446: "XSL must remain on: its seam blend is essential at and below 0.5 bpp; cannot be
     removed".  LSv2 S5.344 L3585: the display seam blend stays (removing it = seam line).  LSv2 S5.345 L3587:
     CORRECTION -- the blend shifts the level of the rows either side of every boundary = the SMUDGE (level-map

 1.8 Legality interaction: the blend is non-convex -- 340 of 343 out-of-range blend writes on dng720 @0.5 have every

    ends derive it; exact) (BS (a); S5.206); XSL off / level 0 self-contained slices (no edit); 16-row slices;
    OMC_VEXT (normative boundary extension inside the transform, no display step) (L53 55.5).

    HVBC pixel-domain blend and interval-bounded display filters / ramps / gradient-fill (display-only, not

    / fill reach (texture synthesis / quantiser gates).

================ 4. WHAT CAUSES THE SEAM LINE WITHOUT A BLEND ================
 - Mechanism: the vertical 5/3 whole-sample mirror at the slice's last pair degenerates the last predict to a first
   difference: x[last] = H[last] + x[last-1]; when H[last] quantises to 0 (common at 0.5 bpp, commoner on chroma)
   the last row is an exact copy; two vertical levels compound it (bottom quarter of the slice collapses to one row)
   (L53 55.2 ~43622-43662).  Duplicate-row fraction rows 13-14 (1080p sh16 @0.5): Y 0.532 / Cb 0.671 vs interior
   0.12 / 0.10, source 0.029 / 0.027; tracks slice height (moves to phase 7 at sh 8); Cb seam step 12.17 vs 5.7
   interior (55.2).  §78.10 later removed the replication (phases 13/14 0.223 -> 0.020) but pitch rose (L53 55.7).
 - Bands: the vertical highpass bands -- LH1 (b7), HH1 (b9) at level 1, b4/b6 at level 2 (LSv2 S5.103 rule); odd
   rows = vertical highpass rows, the first zeroed at 0.5 bpp (S3.10 L927).
 - Per-row error, 720p sh8 @0.5 frame 2 (step tree): Y 14.7 15.9 14.3 16.9 13.5 17.4 15.8 19.3 (odd +12 %, last row
   +30 %); cf_gfx sh8 last +23 %; 1080p sh16 last +30 %; Cb 720p 19.1 ... 23.7 (S3.10).
 - Boundary rows carry 30-60 % excess quantisation noise energy (XSL "Why it exists"; BS ~872).
 - Without the blend, rate dependence (seam step as multiple of interior step): city 1.824 / 1.269 / 1.067 / 1.013
   and beach 1.705 / 1.294 / 1.048 / 1.021 at 0.5 / 1.0 / 2.0 / 3.0 bpp (XSL "The seam is rate-dependent").
   No-edit seam excess (T5 10.4): +4.36 codes @0.5, +2.64 @1.0 (cine), +2.95 / +1.88 (gfx444), source ~+0.2.
   XSL off vs level 3, seam SPATIAL excess: +8.86 vs +2.59 @0.5, +3.68 vs +0.82 @1.0 (SL12 PART XXII).
   Cold intra frame 3-14x worse than steady (city @0.5 f0 +12.71 sh8 / +10.32 sh16 vs f5 +7.37 / +5.01) (SL12 V).
 - Slice-pitch periodicity (pitch.py, dng @0.5, no fill-cure): v5.2 shipped 0.083/0.093/0.078 vs XS @0.5
   0.027/0.034/0.033 and source 0.020/0.009/0.008; cityalley 0.214 vs XS 0.026 (L53 55.7).  DC component at the seam
   is NOT the problem in OMC (luma seam DC 0.97 of interior; XS 1.32) -- what remains is an 8-11 % texture
   modulation phase-locked to the slice (L53 55.4).
 - 720p 8-row: the smudge carrier is the inter residual size the 8-row geometry cannot represent (8 -> 4 -> 2
   vertical samples), r = +0.78 with source motion (LSv2 S5.99); refresh slice starvation (S5.102).
