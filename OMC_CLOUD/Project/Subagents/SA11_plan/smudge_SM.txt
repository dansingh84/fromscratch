     row -0.11...+0.05) and in every eighth of the frame height, already on frame 0 (dng720 f0 Y +0.9...+1.1, Cb +0.8...
     +1.1, Cr +0.8...+1.1; spot f0 +0.8...+1.1) and unchanged on frames 1, 8, 11.  Mechanism (measured on one row,
     notes/exact_e.py): the intra row predictor (a + 2b + c + 2) >> 2 rounds half up (+0.125 code per row on average)
     and the vertical chain carries it; the residual that would correct it stays inside the dead zone of the coarse band
     (coarse step 8 at Qf 6.5), so the level settles about +1 code high; inter rows inherit it (zero-residual copy).
     No downward ramp within the slice.

 codec: Y first row +0.25...+0.36, last row -0.06...-0.40; chroma first row +0.38...+0.55 (the seam rows).
