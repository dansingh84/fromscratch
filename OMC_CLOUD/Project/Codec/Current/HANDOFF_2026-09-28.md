### 4.1 The design (as of round 2)
- **Transform:** Haar-type pair pyramid, pair mean + predicted pair difference (2/6 "TS" form), 5 horizontal × 2 vertical levels (4:2:0 chroma Lv = 1). Split never crosses a 4-row block; each block's neighbour means are sent one step ahead in the stream for EVERY block → a slice edge is an ordinary block edge; slices are packet/rate units only. Slice height S = 4 (720p, 8K) / 8 (1080p, 2160p).
- **Legality:** decoder clamps each pair difference (and mean) into an interval computed from already-final values; no cycle, no search, no clip. Canonical index = smallest-magnitude index reproducing the value (round 2).
- **Temporal:** lattice-locked prediction — motion compensation predicts quantisation INDICES (hint), every coefficient reconstructed as an intra lattice point → picture independent of the reference (refresh, joins, loss recovery are exact by construction). Vectors: block match of the current picture vs the reference; the emitted description uses the vectors of the same search on the encoder's own reconstruction (canonical). No second reference frame (round 2).
- **Symbols open-loop** (round 2) so exact per-candidate code lengths are known in one pass (cost −0.02…−0.09 dB Y/Cb/Cr).
- **Rate control (round 2):** exact CBR prefix bound, one knot per slice (1/8-octave), linear ramp inside the slice, 25-candidate lanes evaluated in parallel, no guard, no partial-slice mode; still content kept by keeping the previous frame's knot when it fits (per-coefficient step memory was REJECTED for 8K memory).
- **Plan reading:** knot = coarsest candidate under which every coefficient is reproducible (legal intervals counted); gen 1 emits what the reading returns (proof by induction in DESIGN_v2 R8). Backtrack removed.
- **Tables:** 60 static tANS tables, L = 1024, 1.1 Mbit.
- **Loss (A5):** one-way bit-metered background refresh sweep (rho = 1/16 reservation), clean-region rule for vectors above the front; on-demand refresh if a back channel exists.
